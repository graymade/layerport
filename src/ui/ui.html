Layerport

Figma to layered PSD
Select frames or whole Sections, then export. Text stays live and editable, image layers embed as hi-res Smart Objects, groups and blend modes carry over. Files land in your Downloads folder.

Output

Skips Smart Object embedding (AE reads preview pixels only), so image layers arrive as plain pixel layers at canvas resolution. Pair with 2x for scaling headroom.

Extra files

TIFF carries the resolution tag above so it opens at print size. CMYK uses the standard formula, not an ICC profile; run final separations through a color-managed tool.

Naming

Tokens: {frame} {page} {date} {n} {width} {height}
Batch rename map
Frames tagged [#ID] in their name export under the filename mapped to that ID, overriding the template. Paste JSON ({"123": "filename"} or rows) or CSV lines (id,filename).
